# 2022~2024 표본 외 판정 (ROADMAP P1)

> 요약: 2026년 데이터로 설계한 9개 알파를 설계에 쓰지 않은 2022-01-13 ~ 2024-12-31(OOS-1, 12종목)에서 사전 등록 기준대로 **한 번** 판정했습니다. **기준을 통과한 알파는 없습니다.** 켜져 있던 `htf_trend`(평균 -0.042R, t_day -1.07), `intraday_levels`(-0.129R, -3.92), `momentum_burst`(-0.161R, -3.81)는 모두 기본 비활성으로 바뀌었고, 꺼져 있던 6개도 그대로 꺼져 있습니다. 출하 기본값에서 켜진 알파는 0개입니다. 봇은 PAPER 모드에서 신규 진입 없이 데이터 수집과 재검증만 합니다. ROADMAP이 미리 정해 둔 정상적인 결론입니다. 이전 기본 구성(3개 알파)의 공동 포트폴리오는 세 해 모두 손실이었고(-4.7%, -13.6%, -2.5%), 매년 고점 대비 -15% 정지에 걸려 남은 기간 거래하지 못했습니다.

## 1. 목적과 사전 등록

- 2026-01 ~ 10월 데이터(TRAIN / VALID / HOLDOUT)는 현재 알파 설계에 이미 모두 쓰였습니다. HOLDOUT에서 앙상블은 -0.035R이었습니다(`docs/RESEARCH.md` 5절). 그래서 어떤 설계에도 쓰이지 않은 2022~2024년으로 다시 판정했습니다.
- 판정 기준은 데이터를 보기 전에 `docs/ROADMAP.md` P1(커밋 `0ae5e7c`)에 고정했고, 그대로 기계적으로 적용했습니다. 결과를 본 뒤 알파 코드, 파라미터, 필터, 종목, 연도는 바꾸지 않았습니다.

| 대상 | 켜짐 유지 / 켜기 조건 (모두 충족) |
|---|---|
| 켜져 있던 3개 (`htf_trend`, `intraday_levels`, `momentum_burst`) | 합산 평균R > 0, t_day ≥ 2.0, 3개 연도 중 2개 이상 평균R > 0, 스트레스 합산 평균R > 0 |
| 꺼져 있던 6개 (`trend_pullback`, `squeeze_breakout`, `mean_reversion`, `funding_fade`, `sweep_reversal`, `positioning`) | 합산 평균R ≥ +0.05, t_day ≥ 3.0, 3개 연도 모두 평균R > 0, 스트레스 합산 평균R > 0 |

`discovered`는 규칙이 없으므로 판정 대상이 아닙니다.

## 2. 실행 조건

- **코드**: 커밋 `9608578`(P0, P0b 이후 P1 준비 커밋). 18개 결과 파일 모두 `git_commit`이 이 커밋이고 `git_dirty`가 false입니다(`heartless/`에 커밋되지 않은 변경 없음).
- **데이터**: `data/longhist/heartless.db`, 핵심 12종목(BTC ETH SOL XRP DOGE ADA AVAX LINK LTC BCH BNB SUI). SUI는 2023-05-03 상장이라 2022년 작업은 "not enough candles"로 비어 있고(예상된 결과), 2023년은 12일 워밍업 뒤인 2023-05-15 16:00부터 평가했습니다.
- **기간**: `--start 2022-01-13 --end 2025-01-01`(날짜만 쓴 끝은 미포함이므로 2024-12-31 23:59까지). 2025 봉인 구간과 겹치지 않습니다(`seal.clean = true`, 개봉 원장 기록 없음).
- **파라미터**: 출하 기본값. `data/longhist`에는 저장된 챔피언이 없으므로 lab이 `StrategyParams.default()`를 썼고, 결과 파일의 `params_version`은 `v0-default+lab`입니다. `--params`, `--set`은 쓰지 않았습니다.
- **평가 방식**: 단일 알파 lab(종목별 독립 계정, 계정 손실 정지 끔, 거래당 0.5% 위험). 명목 비용(테이커 5bp, 메이커 2bp, 슬리피지 1.5bp)과 스트레스(수수료 1.5배, 슬리피지 2배)를 각각 한 번씩 돌렸습니다.
- 3년은 (종목 × 달력 연도) 작업 36개로 나눠 7일 번인·런오프로 이어 붙였습니다. 18개 실행 모두 조각 경계에서 강제 청산된 거래가 0건이어서, 경계 포함 수치와 제외 수치가 같습니다.
- **실행**: 18회, 각 579~715초(작업자 3개, 다른 작업과 4코어 공유). 충돌이나 재실행은 없었습니다.

```bash
SYMS=BTCUSDT,ETHUSDT,SOLUSDT,XRPUSDT,DOGEUSDT,ADAUSDT,AVAXUSDT,LINKUSDT,LTCUSDT,BCHUSDT,BNBUSDT,SUIUSDT
for a in htf_trend intraday_levels momentum_burst trend_pullback squeeze_breakout mean_reversion funding_fade sweep_reversal positioning; do
  HEARTLESS_DATA_DIR=data/longhist ARCHIVE_BACKFILL=false heartless lab --alpha $a --start 2022-01-13 --end 2025-01-01 \
    --symbols $SYMS --by-side --workers 3 --out docs/results/p1_${a}_nominal.json
  HEARTLESS_DATA_DIR=data/longhist ARCHIVE_BACKFILL=false heartless lab --alpha $a --start 2022-01-13 --end 2025-01-01 \
    --symbols $SYMS --by-side --workers 3 --stress --out docs/results/p1_${a}_stress.json
done
```

실제 실행에는 거래 목록을 작업 폴더로 내보내는 `--trades-out`도 붙였습니다(각 결과 파일의 `argv`). 출력만 추가하는 옵션이라 결과에는 영향이 없고, 3절의 청산일 수는 이 목록에서 셌습니다. 판정 입력값과 조건별 참/거짓은 `docs/results/p1_decisions.json`에 있습니다.

## 4. 출하 기본값의 변경

- `htf_trend`, `intraday_levels`, `momentum_burst`의 `enabled_by_default`를 `False`로 바꿨습니다(커밋 `0d238e7`). 알파 코드와 파라미터는 그대로입니다.
- 꺼져 있던 6개는 그대로입니다. 출하 기본값에서 켜진 알파는 0개입니다.
- 설계 지문에 기본 활성 여부가 포함되므로, 운영 봇의 저장 챔피언·챌린저에서도 세 알파는 출하 기본값(꺼짐, 기본 파라미터)으로 돌아갑니다(`StrategyParams.from_stored`).
- 시작 로그와 Telegram 시작 메시지에는 "⚠️ 검증을 통과한 활성 알파 없음 — 신규 진입 없이 데이터 수집·재검증만 진행"이 표시됩니다.

- `htf_trend`가 2022년에 낸 이익은 숏(+0.147R)에서만 나왔고 롱은 -0.166R이었습니다. RESEARCH.md가 경고한 "하락장 숏 드리프트"와 같은 모양입니다. 상승장인 2023~2024년에는 롱도 이기지 못했습니다.
- `squeeze_breakout`의 양수도 2023~2024년 상승장의 롱(+0.163, +0.107)이 만든 것이고 숏은 음수입니다.
- 결과는 RESEARCH.md 7절의 선택 편향 경고(알파마다 TRAIN lab 수십 회, 일부 값은 VALID에서 선택)와 일치합니다. 2026 HOLDOUT의 -0.035R이 첫 신호였습니다.

**표본은 충분히 큽니다.**

- 알파마다 거래 850~12,500건, 거래가 끝난 날 290~1,080일입니다. 거래 수는 2026 TRAIN의 약 4~11배입니다.
- `intraday_levels`, `momentum_burst`, `mean_reversion`, `sweep_reversal`, `positioning`은 t_day가 -2.6 ~ -7.5입니다. "엣지의 증거가 없다"가 아니라 "비용을 뺀 기대값이 음수라는 증거"입니다. 연도별로도 일관되게 음수입니다.
- `htf_trend`, `trend_pullback`, `funding_fade`, `squeeze_breakout`은 0 근처(|t_day| ≤ 1.1)입니다. 비용을 넘는 엣지가 없습니다. 스트레스 비용에서는 모두 음수입니다.

**비용**

- 스트레스 비용은 평균R을 0.015~0.035R 더 낮춥니다.
- 거래가 많은 `sweep_reversal`(n=12,514)과 `trend_pullback`(n=9,831)은 거래당 엣지가 0 근처여서 비용이 그대로 손실이 됩니다.

**알파별 특이 사항**

- `mean_reversion`: 851건 중 771건이 레짐 전환 청산(평균 -0.13R)으로 끝났습니다. 승률 7%, 평균 보유 73분입니다. 2026년 연구에서 관찰한 것과 같은 구조입니다. P0b는 이 청산을 신호 옵트인으로 바꿨을 뿐 동작은 바꾸지 않았습니다.
- `funding_fade`, `positioning`(데이터 한계): 공개 아카이브의 탑트레이더 롱숏비율이 2022년 대부분 비어 있습니다. ETHUSDT 기준 2월~4월과 7월~11월은 거의 0행이고, 테이커 매수/매도 비율도 1~4월에 없습니다. 그래서 두 알파의 2022년 거래가 69건, 150건으로 적습니다. 두 알파 모두 2023~2024년만 봐도 음수이므로 판정은 같습니다.

**운영 봇에게 의미하는 것**

- 출하 기본값으로는 어떤 알파도 거래하지 않습니다. PAPER 모드에서 실시간 데이터 수집, 4시간 리서치 사이클(꺼진 알파 재평가), 매일 알파 발굴이 계속됩니다. ROADMAP이 미리 받아들이기로 한 결론입니다.
- 실거래는 권하지 않습니다.
- 주의: 지금의 챔피언/챌린저 승격 규칙은 이 상태에서 동작하지 않습니다.
  - `heartless/learning/research.py`의 `evaluate_challengers`는 같은 기간 챔피언 거래가 `max(10, PROMOTION_MIN_TRADES/2)`(기본 12)건 이상일 때만 비교합니다.
  - 챔피언이 거래하지 않으면 리서치 사이클이 켠 챌린저를 제안해도 영원히 승격되지 않습니다. 열위 은퇴도 일어나지 않고, avgR < -0.5 조기 탈락만 동작합니다.
  - 시작 메시지의 "리서치 사이클이 통과 알파를 켭니다"는 현재 코드에서는 성립하지 않습니다. P4에서 고쳐야 합니다.
- 리서치 사이클의 재활성 판정은 30일 창, 거래 단위 통계입니다. 이번처럼 2026년 수개월에서 좋아 보인 것이 3년 표본 밖에서 음수였던 사례를 생각하면, 짧은 창의 통과는 약한 증거입니다(P4의 120일 창, 일 단위 통계 전환과 같은 맥락).

## 7. 다음 단계 (P2)

- 2022~2024는 이제 P2의 TRAIN입니다. 2026(RECENT)은 VALID, 2025는 봉인된 최종 시험으로 남습니다.
- 실패한 9개 알파는 TRAIN(2022~2024)에서 재설계하거나 버립니다. 시도한 변형 수 N을 기록하고, t_day ≥ max(3, √(2 ln N)), 3개 연도 중 2개 이상 양수, 스트레스 양수를 요구합니다.
- 연도 × 방향 표에서 보듯 이번 알파들의 이익은 대부분 시장 방향 드리프트였습니다. P2의 시장 컨텍스트(상대강도, 시장 폭, BTC 레짐)와 코인 간 비교 알파는 방향 드리프트를 빼고 평가해야 합니다. 발굴 엔진의 "같은 달·같은 방향 대비 초과 R" 같은 기준이 필요합니다.
- P4에서 먼저 고칠 것:
  - 챔피언이 거래하지 않을 때의 승격 규칙(위 6절)
  - 리서치 창 확대와 일 단위 통계
- 공동 포트폴리오 도구(`heartless backtest --start/--end`)는 P3(신호 일괄 결정, 위험 예산 한도)의 비교 기준으로 씁니다. 고점 대비 정지가 연중 래치되는 동작도 P3/P4에서 백테스트 해석과 함께 다시 봐야 합니다.
